# **Communication with SmartCard Wallet** 
## **Install javascript module**
>   ### **For Application User**
>- [npm i smartcard](https://www.npmjs.com/package/smartcard "SmartCard Module")
>- [npm i aes-cmac ](https://www.npmjs.com/package/aes-cmac "AES_CMAC Moudle")
>- [npm i ethereum-public-key-to-address](https://www.npmjs.com/package/ethereum-public-key-to-address "Public Key to Address Ethereum Module")
>- [npm i crypto-js](https://www.npmjs.com/package/crypto-js)

>  ### **For Vendor**
>- [npm i smartcard](https://www.npmjs.com/package/smartcard "SmartCard Module")
>- [npm i aes-cmac ](https://www.npmjs.com/package/aes-cmac "AES_CMAC Moudle")
>- [npm i elliptic](https://www.npmjs.com/package/elliptic "Elliptic Module")
>- [npm i js-sha256](https://www.npmjs.com/package/js-sha256 "SHA256 Module")
>- [npm i crypto-js](https://www.npmjs.com/package/crypto-js)
